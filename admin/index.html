后台通过 GitHub API 直接写入这个仓库，无需服务器。请填写一个仅限本仓库的细粒度 Token。

HOW TO

  1. 打开 GitHub → Fine-grained tokens
  2. Repository access 只选 Lihongbo-Learn/lihongbo-learn.github.io
  3. Permissions → Contents 设为 Read and write
  4. 生成后粘贴到上方。Token 只保存在你的浏览器里，不会提交到仓库。

不要在此处使用账号密码，也不要把 Token 发给别人。Token 等同于这个仓库的写权限。
