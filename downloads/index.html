LARGE FILES / 大文件

为什么文件不在本站？

主页部署在 GitHub Pages，单文件限制 100 MiB；大文件放在 GitHub Releases，单个附件上限 2 GiB，官方文档不限制 Release 总大小与下载带宽（受合理使用约束）。

超过 2 GB 的文件会拆成多个分卷，每个分卷都列在文件卡片里；全部分卷下载到同一目录后，解压第 1 个分卷即可。

加速镜像：所有 github.com 文件会自动追加 gh-proxy.org 镜像，原始 GitHub 链接仍然保留。镜像由第三方提供，可能限速或失效，下载后可用 SHA-256 校验。参见 gh-proxy 文档 ↗。

BEFORE DOWNLOAD / 下载前
  • 核对文件大小与 SHA-256。
  • 大文件建议使用浏览器或下载工具，支持断点续传。
  • GitHub 下载速度受网络环境影响，可优先使用镜像。
  • 所有文件公开；需要密码的文件会单独说明。
